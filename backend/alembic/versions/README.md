# Migration history

Каждый Python-файл здесь — отдельная миграция Alembic с `revision`, `down_revision`, `upgrade()` и `downgrade()`. Файлы должны оставаться в истории в порядке зависимостей; их имена и идентификаторы используются Alembic для отслеживания текущей версии БД.

Для новой схемной правки создайте новую миграцию из `backend/` командой `alembic revision --autogenerate -m "..."`, затем проверьте SQL и обе функции. Не запускайте миграции удалением/переименованием файлов.
