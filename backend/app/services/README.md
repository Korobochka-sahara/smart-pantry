# Business services

Сервисный слой реализует правила предметной области и операции с БД, вызываемые API-роутерами.

- `auth_service.py` — регистрация, аутентификация, refresh-token storage/revocation.
- `household_service.py` — создание домохозяйств, membership и роли.
- `inventory_service.py` — создание, изменение, удаление и чтение запасов.
- `product_service.py` — каталог товаров.
- `tracked_product_service.py` — минимальные остатки и low-stock.
- `auxiliary_functions.py` — общие проверки доступа и доменные исключения.
- `product_matching.py` — нормализация и ранжирование кандидатов из `Product` для позиций чека.
- `mineru.py` — HTTP-клиент ML OCR-сервиса.
- `ocr_service.py` — координация MinerU, Qwen-парсера и product matching; не записывает распознанные позиции в инвентарь.
- `receipt_parser.py` — вспомогательная/ранняя реализация парсинга Markdown; проверь её использование перед расширением.

Сервисы должны проверять права доступа, не полагаться на то, что фронтенд прислал безопасные данные, и не скрывать ошибки инфраструктуры без логирования.
