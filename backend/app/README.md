# app — код backend

Корневой Python-пакет приложения. `main.py` собирает FastAPI-приложение и регистрирует роутеры. `security.py` реализует JWT и зависимости авторизации. Остальные обязанности разделены по каталогам `api`, `db`, `enums`, `models`, `schemas`, `services`, `tasks`.

Правило зависимостей: `api` вызывает `services`; сервисы используют ORM-модели и `db`; схемы описывают внешний контракт. Не размещайте бизнес-логику в роутерах, если её можно вынести в сервис.
