# Background tasks

`cleanup.py` содержит периодическую очистку просроченных или отозванных refresh-токенов. Планировщик запускается из `app/main.py` через APScheduler при старте приложения и корректно останавливается при завершении.

При запуске нескольких worker-процессов in-process scheduler может запускать одну и ту же задачу несколько раз. Перед масштабированием вынеси расписание в отдельный worker или обеспечь единственный экземпляр scheduler.
