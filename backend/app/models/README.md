# SQLAlchemy models

ORM-модели соответствуют таблицам PostgreSQL:

- `user.py` — пользователь и хеш пароля.
- `refresh_token.py` — хеши refresh-токенов, сроки действия и отзыв.
- `household.py`, `household_member.py` — домохозяйства и членство/роль.
- `product.py` — глобальный каталог товаров.
- `inventory_item.py` — количество товара в конкретном домохозяйстве.
- `tracked_product.py` — настройка минимального остатка.

Модели определяют поля, типы, связи и ограничения БД. Не путай `Product` (описание товара) с `InventoryItem` (запас конкретного домохозяйства). При изменении схемы создайте и проверьте миграцию Alembic.
