# Pydantic schemas

Схемы определяют формы входных запросов и ответов API и проверяют типы данных на границе приложения. Файлы сгруппированы по функциональности: `auth.py`, `household.py`, `product.py`, `inventory_item.py`, `tracked_product.py`, `ocr.py`.

Не возвращайте ORM-объекты с секретами напрямую: создавайте явные response-схемы. Если меняется контракт endpoint, синхронно обновите соответствующие тесты и README API.
