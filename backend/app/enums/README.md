# Enums

Перечисления общих доменных значений: `household.py` описывает роли участников домохозяйства, `category.py` — категории товаров, `unit.py` — единицы измерения. Значения Enum должны согласовываться со схемами Pydantic и существующими PostgreSQL enum-типами. При изменении уже созданного Enum нужна миграция Alembic.
