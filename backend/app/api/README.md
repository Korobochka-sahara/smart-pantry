# API endpoints

Здесь находятся FastAPI-роутеры. Каждый файл описывает HTTP-маршруты одного функционального блока:

- `auth.py` — регистрация, login, refresh, logout, текущий пользователь.
- `household.py` — домохозяйства и участники/роли.
- `product.py` — каталог товаров.
- `inventory.py` — запасы домохозяйства.
- `tracked_product.py` — контроль минимальных остатков.
- `ocr.py` — загрузка чека, валидация формата/размера и вызов `OCRService`.

Роутер отвечает за HTTP-коды, зависимости FastAPI и сериализацию. Бизнес-правила должны находиться в `app/services/`. Проверить endpoint можно в Swagger: `/docs`.
