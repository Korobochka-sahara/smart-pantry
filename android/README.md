# Smart Pantry — Android

Android-клиент Smart Pantry на Kotlin и Jetpack Compose. Приложение подключается к FastAPI, поддерживает вход/регистрацию, семьи, запасы продуктов, OCR-чека и список отслеживаемых продуктов с минимальным остатком.

## Запуск в Android Studio

1. Запустите backend и PostgreSQL по инструкции в корневом README.
2. Откройте папку `android` в Android Studio и дождитесь Gradle Sync.
3. В `data/remote/ApiClient.kt` проверьте `BASE_URL`:
   - эмулятор Android: `http://10.0.2.2:8000/`;
   - физический телефон: `http://IP_КОМПЬЮТЕРА_В_ЛОКАЛЬНОЙ_СЕТИ:8000/`.
4. Запустите приложение на выбранном устройстве и войдите в аккаунт.

Для временной настройки экрана выбора распознанных товаров включён UI-мок: `USE_OCR_UI_MOCK = true` в `InventoryScreen.kt`. Он не запускает долгий OCR, а показывает демонстрационные строки с кандидатами из каталога. Для настоящего OCR установите значение `false`.

## Запуск на физическом Android-телефоне

- Телефон и компьютер должны быть подключены к одной Wi-Fi-сети.
- Узнайте локальный IPv4-адрес компьютера (Windows: `ipconfig`) и укажите его в `BASE_URL` вместо `10.0.2.2`.
- Backend должен слушать `0.0.0.0:8000`, а не только `127.0.0.1`; откройте входящее TCP-соединение на порт 8000 в брандмауэре Windows для частной сети.
- Разрешение HTTP для разработки уже должно соответствовать настройкам `AndroidManifest.xml`. Не используйте такой незашифрованный HTTP для публичной сети: для доступа извне настройте HTTPS.

## Сборка APK

В Android Studio выберите **Build → Build APK(s)**. Для установки на телефон передайте APK на устройство и откройте его, разрешив установку из выбранного источника при запросе. Для распространения другим пользователям создайте подписанный APK через **Build → Generate Signed Bundle / APK**.
