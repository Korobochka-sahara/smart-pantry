# Android Smart Pantry

Адрес API задаётся при сборке. Все команды выполняются в C:\Users\korobochka_sahara\projects\smart-pantry\android> 

## Эмулятор

По умолчанию используется `http://10.0.2.2:8000/`:

```powershell
.\gradlew.bat assembleDebug
```

## Телефон в домашней сети или внешний сервер

Запустите backend на доступном сервере. Для телефона в одной Wi-Fi-сети используй LAN IPv4 компьютера; для внешнего сервера — его IP или домен.

```powershell
.\gradlew.bat assembleDebug "-PpantryApiBaseUrl=http://203.0.113.10:8000/"
```

`203.0.113.10` — пример, замените реальным адресом. Такой же параметр можно указать в Gradle Run Configuration Android Studio либо добавить `pantryApiBaseUrl=http://ВАШ-СЕРВЕР:8000/` в пользовательский `%USERPROFILE%/.gradle/gradle.properties`.

Один адрес используется и для обычных запросов, и для обновления токенов. Завершающий `/` добавляется автоматически. APK: `app/build/outputs/apk/debug/app-debug.apk`. После смены сервера выйди из прежнего аккаунта и войди на новом сервере. Смена адреса требует пересборки приложения.

## OCR

По умолчанию используется настоящий сервер OCR. Чтобы собрать и установить демо-версию на запущенный эмулятор или подключённый телефон, выполните из каталога `android`:

```powershell
.\gradlew.bat :app:installDebug '-PpantryOcrMock=true'
```

`assembleDebug` только создаёт APK. Если используете эту команду, установите полученный APK вручную. После `installDebug` откройте приложение с устройства. Запуск кнопкой Run в Android Studio может пересобрать приложение с настройками IDE. Чтобы включить деморежим и для сборок из IDE, добавьте `pantryOcrMock=true` в `android/gradle.properties` и запустите сборку снова.

На экране запасов появится надпись «Демо-режим OCR». Приложение подставит молоко, хлеб и яйца и поищет совпадения в каталоге. Для поиска кандидатов нужен доступный бэкенд. Запрос к OCR не отправляется.

## Проверка

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest
```

`ApiContractTest` проверяет Enum единиц/категорий, чтение дробных количеств как JSON-строк и чисел и передачу ожидаемого остатка при ручном редактировании.
