# Test receipt images

Изображения чеков, используемые для ручных OCR-экспериментов и проверки обработки. Скрипты EasyOCR/PaddleOCR по умолчанию используют `receipt_01.jpg`; остальные файлы позволяют расширить набор примеров.

Запуск из корня репозитория:

```powershell
python ml/ocr/easyocr_test.py
python ml/ocr/paddleocr_test.py
```

Добавляя изображения, следи за правами на данные и удаляй/маскируй личные сведения, номера карт, адреса и другие чувствительные поля. Для воспроизводимости используй стабильные имена и веди отдельные результаты по каждому чеку.
