# OCR results

Здесь хранятся сохранённые JSON-результаты ручных запусков OCR. Они полезны для сравнения форматов и ошибок распознавания, а не являются частью runtime-приложения.

Подкаталоги `easyocr/`, `mineru/`, `paddleocr/` группируют результаты по движку. Не перезаписывай результаты разных моделей одним именем; включай в имя файла номер чека и режим обработки.
