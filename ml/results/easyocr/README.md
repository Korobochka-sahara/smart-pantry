# EasyOCR results

JSON-файлы с результатами `ml/ocr/easyocr_test.py`. Обычно содержат движок, имя изображения, время обработки и распознанные текстовые фрагменты с confidence и bounding boxes.

Повторный запуск базового скрипта перезаписывает `easyocr_receipt_01.json`; скопируй результат под новым именем, если нужно сохранить сравнение разных версий.
