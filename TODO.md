для начала реализации курсовой я описала два пункта:
1. Зафиксировать объём исследования.
Подробное описание сущностей:
Пользователь(user): основные возможности - регистрация, авторизация
семья(household): создание, удаление, пользователи внутри(роли, удаление/добавление, выход), список продуктов семьи, отслеживаемый список
член семьи (household_member): роли, удаление/добавление, выход
товар (product): База со всеми товарами
houshold_item: продукты, которые есть в конкретной семье
inventory: семьи с продуктами
список покупок tracked_product: регулируемый список, в который добавляются товары, за которыми происходит автоматическая слежка - пользователь видит сразу, есть товар или нет и что надо купить

История расходования, сроки годности и партии не будут реализованы в формате курсовой.
2. Описать единый контракт операций.
   Например:
   - создать пользователя;
   - зайти в аккаунт;
   - получить запасы семьи;
   - найти товар по названию;
   - добавить товар;
   - пополнить остаток;
   - списать количество с запретом отрицательного остатка;
   - изменить минимальный запас;
   - получить список недостающих товаров;
   - удалить семью вместе с зависимыми данными.
